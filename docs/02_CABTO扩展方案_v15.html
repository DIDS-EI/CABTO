2.3 关键指标实现（开箱即跑）

Learning Curve Slope（跨 episode 学习曲线斜率，杀手锏指标）
对同一任务连续跑 N=20 episode，每 episode 失败后给反馈，记录 SR 序列 (SR_1, ..., SR_N)
slope = LinearRegression().fit(range(N), SR_seq).coef_[0]
预期：CABTO slope > 0.02，三个 baseline ≈ 0
Feedback Utilization Rate
Util = (反馈后 SR − 反馈前 SR) / 反馈带来的额外 token 成本
衡量"反馈是否物有所值"

§7 5.4 节 Theoretical Analysis 占位骨架（先写定理框架）

定理 1（单调收敛性）

设连续 N 个 episode 中，CABTO 累积反馈约束集合 𝒞_N 单调递增，且 LLM 在 prompt 中严格遵守 prior_update_hint。
则任务成功率序列 {SR_n}_{n=1}^N 在期望意义下满足：
  𝔼[SR_{n+1} | 𝒞_n] ≥ 𝔼[SR_n | 𝒞_{n-1}]
即跨 episode 不降，且若 𝒞_n 严格扩展则严格递增。

定理 2（反馈带宽下界）

设任务真实最优策略 π* 在状态空间 𝒳 上诱导失败模式分布 P(F | 𝒳)，则上行接口 ℐ↑ 至少需传输信息量：
  |ℐ↑| ≥ H(F) − I(F; ℐ↓)
否则 LLM 无法在 finite episode 内收敛到 π*。
写法策略：定理证明可简略（半页 sketch），关键是把"反馈带来的信息增益"形式化出来。评委只要看到有数学定理框架，就会认为 chap05 是"理论 + 方法 + 实验"的完整章。
