PROBLEM ALIGNMENT

本研究的核心问题，与领域如何对话

CABTO 把一个高层技能落地为可执行行为，分解为两部分学习：符号层的动作模型 h=⟨pre, add, del⟩（前置条件 / 添加效果 / 删除效果），与连续层的控制策略 π。要让同一套技能在多个机器人上成立，关键在于：动作模型的语义 grounding 是否在不同本体、不同初始状态上稳健成立，以及 π 能否被高效采样/迁移。下面五条主线分别从不同角度回应这一问题。

五条主线如何映射到 CABTO

  • ① 动作模型 / 符号语义学习 —— 直接对标 h=⟨pre,add,del⟩ 的自动获取与 grounding 验证（UniDomain、PSALM-V、GRAIL）。
  • ② 跨本体 / 多机器人技能学习 —— 对标"同一技能在多机器人上成立"的本体无关表征与迁移（Open X-Embodiment、UniSkill、LEGATO）。
  • ③ VLA 基础模型 —— 对标 π 的通用化：用大规模数据训出可迁移的低层控制（OpenVLA、π0/π0.5、RDT、GR00T）。
  • ④ 具身多智能体协作 —— 对标多机器人在任务层的协同与角色分配（COHERENT、RoCo、ThinkAct）。
  • ⑤ 行为树 / 分层任务规划 —— 对标 CABTO 的 BT 结构本身与 LLM 驱动的 BT 生成（LLM-as-BT-Planner、LearnAct）。
LINE ① — ACTION MODEL & SYMBOLIC GROUNDING

动作模型与符号语义的自动学习 与本研究最直接对标

这条线研究如何从演示或交互中自动归纳出动作的前/后置条件（precondition / effect）——这正是 CABTO 中动作模型 h 的内核。核心挑战：符号 grounding（把感知映射到谓词）、长程一致性、以及在未见状态上的泛化。

UniDomain：从真实演示预训练统一 PDDL 域

NeurIPS 2025
Haoming Ye, Yunxiao Xiao, Cewu Lu, Panpan Cai（上海交大）
解决的问题LLM/VLM 缺乏长程结构与符号 grounding；已有 LLM+符号规划依赖手工窄域，难泛化。
方法从 12,393 段操作视频抽取原子域，融合成含 3137 算子 / 2875 谓词 / 16481 因果边的统一 PDDL 域；按任务类检索原子域并组装元域，实现零样本规划。
结果真实未见任务零样本，较 LLM 与 LLM-PDDL 基线任务成功率最高 +58%、计划最优性 +160%。
NeurIPS 论文

PSALM-V：交互式视觉环境中自动归纳符号动作语义

arXiv 2025.06
Wang Bill Zhu, Miaosen Chai, Ishika Singh, Robin Jia, Jesse Thomason（USC）
解决的问题已有 LLM 生成 PDDL 语义多限于文本域或依赖不现实假设（完全可观测 / 预置问题文件 / 显式报错）。
方法首个能在视觉环境中通过交互归纳出动作 pre/post-conditions 的神经符号系统；对每个动作维护树状信念，依执行结果与合成错误解释迭代精炼，直到达成目标。
结果ALFRED 部分可观测下计划成功率 37%（Claude-3.7）→ 74%；在真实机器人 BlocksWorld 上正确归纳出 pre/post-conditions。
arXiv 2506.20097

GRAIL：语言模型驱动的接地式机器人动作规则归纳

ICLR 2025 投稿
James Neidhoefer, Jacob Arkin, Nicholas Roy, Chuchu Fan（MIT）
解决的问题自主规划长期需人工预设两件事：动作符号的识别/grounding，以及 PDDL 规则（名称、参数、前/后置条件）。
方法用 LLM 聚类机器人的传感运动经验，自动生成关于自身能力与环境的符号抽象；语言接地的抽象使学到的域无需重训即可修改与规划。
结果在标准迷宫域验证符号识别/grounding、规则自动生成、仿真规则校验与 PDDL 模型优化；论证神经符号混合优于纯符号/纯数据方法。
OpenReview

Teriyaki：基于 LLM 的神经符号机器人动作规划框架

arXiv / 期刊
弥合符号任务规划与机器学习方法之间的差距
解决的问题符号规划在复杂域或频繁重规划时扩展性差，难落地人机协作。
方法把 LLM 训练为与 PDDL 兼容的神经符号规划器，逐动作合成计划（生成即可执行），支持并发规划与执行。
价值随域复杂度增长响应时间近线性；为"边生成边执行"的 BT-like 在线落地提供思路。
arXiv 2303.00438

对 CABTO 的启示

UniDomain / PSALM-V / GRAIL 共同验证了一个判断：动作模型 h=⟨pre,add,del⟩ 可以从数据/交互中自动归纳，而非全靠手工。CABTO 实验 2（low-level policy sampling）正是这一范式在连续操作上的具体实例——用 π 采样验证 h 的 grounding 在未见初始状态上是否成立（我们的留出验证集 40/40 一致即此意义上的 grounding 校验）。

LINE ② — CROSS-EMBODIMENT SKILL LEARNING

跨本体 / 多机器人技能学习 "同一技能跨多个机器人"

这条线直接回应"机器人包括多个机器人的技能学习"。核心思路是构造本体无关（embodiment-agnostic）的技能/动作表征，让一个技能能在不同形态、不同动作空间的机器人间迁移。

Open X-Embodiment / RT-X：跨本体数据与通用策略

CoRL 2023 · 持续更新
22 机构联合（DeepMind 等）
解决的问题机器人学习长期碎片化——每个机器人/任务/环境单独训模型，无法迁移。
方法汇集 22 种机器人、527 技能、16 万+任务、百万级轨迹，统一为 RLDS 格式（归一化 7D 末端动作）；训练 RT-1-X / RT-2-X 通用策略。
结果单一高容量模型在多机器人上呈现正迁移，跨平台提升能力——奠定了"机器人基础模型"的数据基座。
项目主页 GitHub

LINE ④ — EMBODIED MULTI-AGENT COOPERATION

具身多智能体协作 多机器人在任务层的协同

POSITIONING

本研究（CABTO）在前沿图景中的定位

综合来看，CABTO 处在"动作模型学习"（主线①）与"行为树/分层规划"（主线⑤）的交叉点，并以"多机器人技能学习"（主线②）为目标场景，以"流匹配/扩散策略"（主线③范式）为低层 π 的实现。

差异化与互补点

  • 相比 UniDomain / PSALM-V：它们在离散/视觉符号域归纳 PDDL 语义；CABTO 把动作模型 h 直接接地到连续操作与 BT 节点，并用 low-level policy sampling（实验 2）在物理仿真中校验 h 的 grounding——这是符号语义在真实接触动力学上的落地验证。
  • 相比 OpenVLA / π0：它们追求端到端通用 π；CABTO 保留显式符号结构（BT + h），换取可解释性、可组合性与对多机器人的结构化复用。
  • 相比 RoCo / COHERENT：它们解决多机器人任务层协同；CABTO 聚焦单机器人技能的可靠 grounding，是协同系统中每个 agent 可信执行的基础。

实验 2 与领域的对应

本研究实验 2（Low-level policy sampling）在 MuJoCo Franka 环境中，对 skill=pick(object) 用脚本化专家 π 采样，校验动作模型 h=⟨{on_table}, {in_gripper, lifted}, {on_table}⟩ 的一致性。这正是主线①"符号语义 grounding 校验"在连续操作上的实例化——留出验证集（与采集种子完全错开的全新初始状态）上 5 物体 40/40 一致率 1.0，与 UniDomain/PSALM-V 在符号域报告的 grounding 成功率属于同一类指标。
