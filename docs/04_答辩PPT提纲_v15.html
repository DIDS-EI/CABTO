Page 5 · Ch5 CABTO（重头戏，3-4 分钟）

Bottom-Up Feedback via Constraint-Aware BT Optimization

  • 问题：Hierarchical VLA 低层执行失败 → 信号丢失 → 高层 LLM 无法更新 prior
  • 方法：物理约束（reach + collide + torque + skill 可行域）→ 结构化 JSON 反馈块 → 注入 LLM prompt → 重生成 behavior library
  • 关键定理：跨 episode SR 单调不降（5.4 节）
  • 实验：vs Inner Monologue / DoReMi / REFLECT，跨 5 VLM 通用性，4 维消融
  • 杀手锏图：跨 episode 学习曲线，CABTO 唯一上升斜率
[3-4 min] 重点讲跨 episode 学习曲线那张图，说"三个 baseline 是平的，CABTO 是上升的，这就是结构化、持续、可更新 prior 的本质优势"。

评委高频问答（7 条预案）

Q1：你的"分层"和 Brooks 1986 有何区别？
A：用的是 Gat 1998 3T 模板，不是 Brooks Subsumption；基础模型时代实例化为 Hierarchical VLA，参 Hi Robot ICML'25。I2 上行反馈是 2023 前根本做不出来的——结构化反馈 + LLM prior 更新依赖 Transformer + in-context learning。
Q2：5 层 vs 2 层（大小脑）哪个对？
A：v15 采用社区共识的 2 层（高层 / 低层），不细分 5 层，与 Helix/π0/GR00T 工业界标准一致。
Q3：端到端 VLA 已经能 work，分层是不是过时了？
A：工业界 π0.5/Helix/GR00T N1 全部回归分层，正是因为端到端 VLA 在可解释性、可调试性、跨本体上受限。
Q4：为什么 BT 不进标题？
A：BT 是 SQ1 的具体实现，不是论文主线；论文主线是"接口"，BT 在可组合 / 可解释 / 可执行三维度上 Pareto 最优（I1），但并非接口本身。
Q5：CABTO 上行反馈和 Inner Monologue / DoReMi / REFLECT 有何区别？
A：三个 baseline 共享缺陷——反馈一次性、非结构化、不更新 LLM 生成 prior。CABTO 三大差异化：(1) 结构化（BT 节点级）；(2) 持续闭环；(3) 更新 prior。跨 episode 学习曲线上 CABTO 是唯一上升的。
Q6：你的方法依赖 GPT-4o，换成 Qwen 还行吗？
A：跨 VLM 通用性实验跑了 Qwen2.5-VL / 混元 / GPT-4o / Gemini / Claude 五个模型，SR std 在某阈值内，说明 CABTO 不绑死单一模型。
Q7：和 Hi Robot ICML'25、GR00T N1 比有什么区别？
A：Hi Robot 和 GR00T N1 都是 open-loop（失败重 plan），ℐ↑ 是空白；本论文首次给出结构化 + 可更新 prior 的 ℐ↑ 机制，方法上是补它们的空白，工程上完全兼容。
