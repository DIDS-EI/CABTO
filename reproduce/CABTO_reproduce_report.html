0复现思路与可行性

论文实验依赖真实 LLM（GPT-4o）、Molmo+cuRobo 视觉策略、Isaac Sim 仿真与 GPU。本机不具备这些条件。关键观察：作者在结果目录里完整保存了当时每一次真实 LLM 的输出（llm_output.txt）与精化后的动作库。因此可以构造一个 ReplayLLM 重放器替换真实 LLM，让原始实验流水线「代码抽取 → 行为库写盘 → obtea 规划 → sound&complete 验证」在零联网、零费用下完整运行。

1离线重放机制

重放器与原始 btgym.llm.llm_gpt.LLM 接口完全一致，但 request() 不联网，而是返回对应 <task>_try_<i>/llm_output.txt 里当时真实模型的输出。下游的代码抽取、库写盘、规划、验证全部使用原始仓库代码，未作任何篡改。

STEP 1 · 重放

取缓存输出

ReplayLLM 从 70 个 try 目录读出当时 GPT-4o 的 llm_output.txt，原样返回。

STEP 2 · 抽取

写行为库

沿用原始正则逻辑，把 OGAction/OGCondition 代码块写成 exec_lib。

STEP 3 · 规划

obtea 求解

对 easy/medium/hard 三个 goal 调 BTExpInterface 规划出行为树。

STEP 4 · 验证

执行判定

execute_bt 检查从初始态能否到达目标，error=0 即完备且一致。

# ReplayLLM：零联网、零费用替换真实 LLM
class ReplayLLM:
    def set_context(self, task_name, try_idx):
        self._cur_task, self._cur_try = task_name, try_idx
    def request(self, message):           # 与原 LLM.request 同签名
        return self._read_cached_output()   # 读 <task>_try_<i>/llm_output.txt

4实验 2 · Low-level policy sampling

论文实验 2 用 Molmo+cuRobo 在 Isaac Sim 中采样底层控制策略并验证一致性 s_t ⊇ pre∪add\\del。本仓库中该实验没有端到端可运行的主循环：baselines/atoms 是含 fake IK / fake collision / fake RNEA 的脚手架，agent 用 stub LLM，metrics 用随机数据。论文表 2 对照的 OpenVLA/VoxPoser/ReKep baseline 也未在仓库实现。

可复现部分：一致性判定原子

实验 2 唯一能离线全自动跑通的是底层一致性判定的四类原子（可达 reach、碰撞 collide、力矩 torque、技能 skill）及反馈合成 compose_feedback，对应论文中"在仿真里验证策略是否真能造出动作模型声称的状态转移"这一判定逻辑。
